# Painel HTML para experimentar

Arquivo único e independente do site: **CaloriMob-Painel-Administrador.html**. Baixe o HTML (ou o ZIP nesta pasta), salve no computador e abra com dois cliques no navegador.

O painel permite testar frota, modelos, unidades, tarifas, reservas manuais, calendário, vistorias e avisos fictícios. No botão **Aparência**, experimente cores, fundo e modo escuro. **Recomeçar** restaura os exemplos.

Dados e cores ficam no navegador, quando permitido; nada é enviado ao site real. Não há login, banco, API, mensagem ou pagamento real neste arquivo. Use dados fictícios. O arquivo não exige npm, build ou conexão à internet.

Veja [as instruções completas](LEIA-PRIMEIRO.txt). O teste automatizado usou HTTP local sem rede externa; o navegador gerenciado do ambiente bloqueia navegação file://.
